# Portfolio

Welcome to my interactive Unix terminal-based portfolio website! Developed as a showcase for my work as a **Firmware & Embedded Systems Engineer**, this site blends a custom terminal interface with modern responsive web design.

**Live Website**: [abhay.sh](https://abhay202.github.io/Portfolio/)

---

## Interactive CLI Terminal

- Auto-completion with `Tab`.
- Command history using the `ArrowUp` and `ArrowDown` keys.
- Unix-like utilities (`ls`, `cat`, `clear`, `uname`, `neofetch`).

---

## How to Run Locally

Since this is a lightweight, high-performance static website, you do not need any compilation step!

1. **Clone the repository**:
   ```bash
   git clone https://github.com/abhay202/Portfolio.git
   cd Portfolio
   ```
2. **Open in browser**:
   Simply double-click the `index.html` file or run it via a simple local server using `python -m http.server 8000`.
